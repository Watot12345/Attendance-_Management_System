# File Structure Plan
# Library Attendance Monitoring System (LAMS)

> No-code planning document. Defines every file, folder, and its purpose before implementation begins.

---

## Root Level

```
lams-project/
│
├── .env                          ← Secrets (DB, SMTP) — NEVER commit
├── .env.example                  ← Template showing required variables
├── .gitignore                    ← Excludes .env, /vendor, /node_modules, /uploads/*, /logs/*
│
├── config.php                    ← Central config loader. Reads .env, sets timezone, defines constants
├── index.php                     ← Front controller / router. All requests route through here
│
├── tailwind.config.js            ← Tailwind paths and custom colors
├── package.json                  ← Dev deps: tailwindcss

├── README.md                     ← Setup instructions for developers

    ├── Skills.md                 ← Development procedures
```

## /includes — Private PHP (NOT web-accessible)

### /includes/core — Framework Layer

```
/includes/core/
├── Database.php                  ← PDO singleton wrapper. Connection, prepared statement helper, transaction support
├── Router.php                    ← URL router. Maps /path/to/page to /includes/views/path/to/page.php
├── Auth.php                      ← Session auth: login(), logout(), check(), requireRole(), regenerateSession()
├── Validator.php                 ← Input validation: email(), required(), maxLength(), dateRange(), inArray(), file()
├── Response.php                  ← JSON API response helper: success(), error()
├── Session.php                   ← Session management: start(), destroy(), flash(), getFlash()
└── Security.php                  ← Security utilities: csrfToken(), verifyCsrf(), rateLimit(), sanitizeFilename()
```

## /api — AJAX Endpoints (JSON only)

```
/api/
│
├── /attendance
│   ├── scan.php                  ← POST {qr_code, direction} → record scan, compute status, queue alert
│   ├── mark.php                  ← POST {user_id, date, entry_time, exit_time, status, notes} → manual entry
│   ├── update.php                ← POST {attendance_id, exit_time, notes} → update existing record
│   └── delete.php                ← POST {attendance_id} → soft delete (admin only, logged)
│
├── /excuses
│   ├── submit.php                ← POST {student_user_id, date_from, date_to, reason, attachment} → create slip
│   ├── review.php                ← POST {slip_id, action, notes} → approve/reject
│   ├── list.php                  ← GET {status, page, limit} → paginated list
│   └── detail.php                ← GET {slip_id} → single slip details
│
├── /alerts
│   ├── queue.php                 ← POST {student_user_id, type} → manually queue an alert
│   ├── history.php               ← GET {student_user_id, page} → alert history
│   └── test.php                  ← POST {email} → send test email (admin only)
│
├── /analytics
│   ├── summary.php               ← GET {range, grade, section} → summary counts and trends
│   ├── trends.php                ← GET {metric, range} → daily trend data for Chart.js
│   ├── occupancy.php             ← GET {} → current in-library count and list
│   └── export-data.php           ← GET {type, range, filters} → raw data for client-side CSV generation
│
├── /awards
│   ├── calculate.php             ← POST {period_start, period_end, award_type} → run calculation
│   ├── list.php                  ← GET {period_start, period_end} → award results
│   ├── notify.php                ← POST {award_id} → send parent notification
│   └── certificate.php           ← GET {award_id} → generate/download certificate PDF
│
├── /exports
│   ├── attendance.php            ← POST {date_from, date_to, grade, section, format} → generate file
│   ├── tardies.php               ← POST {date_from, date_to, grade, section} → generate file
│   ├── absences.php              ← POST {date_from, date_to, grade, section} → generate file
│   └── download.php              ← GET {file_token} → serve generated file (auth check, then delete)
│
├── /settings
│   └── update.php                ← POST {key, value} → update single setting (validated)
│
├── /users
│   ├── list.php                  ← GET {role, search, page, limit} → paginated user list
│   ├── create.php                ← POST {role, email, password, first_name, last_name, ...role_fields} → create
│   ├── update.php                ← POST {user_id, ...fields} → update
│   ├── delete.php                ← POST {user_id} → soft delete
│   └── reset-password.php        ← POST {user_id} → generate temp password, force change
│
└── /auth
    ├── login.php                 ← POST {email, password} → authenticate, create session
    ├── check.php                 ← GET {} → return current auth status (for JS)
    └── session-refresh.php       ← POST {} → extend session, return new CSRF token
```

## /scripts — CLI / Cron Scripts

```
/scripts/
├── cron_absence.php              ← Daily batch: find students with no entry today, create absence records,
│                                   queue absent alerts. Run at library_close_time + 30 minutes.
├── cron_alerts.php               ← Email processor: fetch pending alerts (limit 50), send via PHPMailer,
│                                   mark sent/failed. Run every 5 minutes.
├── cron_cleanup.php              ← Weekly cleanup: purge alerts older than 1 year, audit logs older than 2 years,
│                                   error logs older than 30 days, temp export files older than 24 hours.
├── cron_backup.php               ← Daily backup: mysqldump to /backups/, compress, rotate (7 daily, 4 weekly, 12 monthly).
├── seed_data.php                 ← One-time: populate test data (students, teachers, attendance records, settings).
└── generate_qr.php               ← One-time or on-demand: regenerate QR codes for all students, save as images.
```

## Naming Conventions

| Element | Convention | Example |
|---------|-----------|---------|
| PHP files | `snake_case.php` | `manual_entry.php` |
| JS files | `kebab-case.js` | `scanner.js` |
| CSS classes | Tailwind utilities | `bg-blue-500 hover:bg-blue-600` |
| Database tables | `snake_case`, plural | `attendance_records` |
| Database columns | `snake_case` | `entry_time`, `is_excused` |
| PHP classes | `PascalCase` | `Attendance`, `ExcuseSlip` |
| PHP methods | `camelCase` | `createEntry()`, `getByDate()` |
| PHP variables | `snake_case` | `$user_id`, `$qr_code` |
| JS variables | `camelCase` | `csrfToken`, `scanResult` |
| Constants | `UPPER_SNAKE_CASE` | `CSV_MAX_ROWS` |
